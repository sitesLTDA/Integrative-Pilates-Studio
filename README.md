# Integrative Pilates Studio

Landing page responsiva para o Integrative Pilates Studio, feita com HTML, CSS e JavaScript puros.

## Arquivos
- `index.html` — estrutura da página
- `style.css` — estilos e responsividade
- `script.js` — links de WhatsApp, ano do rodapé e animações

## Personalização obrigatória
Abra `script.js` e altere `WHATSAPP_NUMBER` para o número real, com código do país e DDD, somente números. Exemplo: `5511999999999`.

No `index.html`, substitua os campos de endereço, horários, Instagram, bairro/cidade e modalidades pelas informações reais. Troque também as imagens ilustrativas, se desejar, e mantenha apenas diferenciais e modalidades que o estúdio realmente oferece.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o GitHub publicar o site e abra a URL exibida na área de Pages.

As fontes do Google Fonts e as imagens remotas precisam de conexão com a internet para carregar.
